# Kế hoạch: Fine-tune BEVFusion LiDAR-only trên SemanticSpray++ + synthetic spray

---

## Mục tiêu

Fine-tune BEVFusion LiDAR-only trên frame **đã bỏ điểm spray**, có và không có
synthetic spray. Đo trên **real spray held-out** xem augmentation có giảm false
positive mà không mất recall xe thật.

---

## Sơ đồ luồng

```
nuScenes checkpoint (lidar-only-det.pth)
              │
              ├──────────────────┬──────────────────┐
              │                  │                  │
         Model 0            Arm A              Arm B
        zero-shot        no augmentation    + synthetic spray
              │          (points[lab!=2])    (points[lab!=2] + plume p=0.5)
              │                  │                  │
              └──────────────────┴──────────────────┘
                                 │
                    ┌────────────┴────────────┐
                    │                         │
             Test: real spray          Clean control
             (12 scene, không augment)  (nuScenes val 196 frame)
                    │                         │
                    └────────────┬────────────┘
                                 │
                    AP@0.5 · Recall · FP/frame · SPF proxy/frame
```

### Bước 2 — Dataset adapter

**Tạo:** `spray/sspp_adapter.py` · `scripts/build_sspp_split.py`

Box conversion (sửa 2026-11-16 sau khi verify bằng số đo trên 534 box
Car/Van; bản cũ `swap x↔y` + `yaw = -θ-π/2` là **SAI** — làm cả 3 box nghiêng
(|θ| ≥ 0,1 rad) rơi từ 90–100 % điểm xe xuống 73–87 %):

```python
dims  = (x_size, y_size, z_size) = (size3D.x, size3D.y, size3D.z)  # không swap
yaw'  = +rotation3D.z                    # cùng quy ước paper = mmdet (CCW từ +x)
z'    = center3D.z - size3D.z / 2        # đáy hộp, không phải tâm
```

Bằng chứng `[ĐO]` (đếm điểm xe label 1 trong hộp, 534 box trên 36 scene):

- 531/534 box có |θ| < 0,1 rad — hai công thức gần như không phân biệt được
  (chênh 0,4 % điểm); phép thử "98 % điểm trong hộp" **không đủ nhạy**, đừng
  dùng nó để chứng minh công thức góc.
- 3 box nghiêng: công thức đúng giữ 90,5 / 100 / 98,4 % điểm xe; công thức cũ
  chỉ giữ 73,1 / 95,3 / 87,4 %.
- z đáy: giữ 97,5 % điểm xe trong hộp; dùng thẳng `center3D.z` chỉ còn 46,8 %
  (hộp lệch lên nửa chiều cao ~1,3 m).
- Đối chiếu paper (arXiv 2406.09945, "LiDAR 3D Bounding Box Annotation"):
  format `[x,y,z,w,h,l,θ]`, (x,y,z) là **tâm**, θ là "orientation around the
  z-axis" — cùng quy ước CCW-từ-+x với mmdet `LiDARInstance3DBoxes`
  (`mit/bevfusion/mmdet3d/core/bbox/structures/lidar_box3d.py`).

Vận tốc box `[CHỌN]`: `(object_velocity_kmh / 3.6, 0.0)` — xe dẫn đi cùng
hướng ego nên vận tốc dọc +x trong hệ LiDAR; đọc từ `metadata.txt`.

**Chạy:**

```bash
CONDA_NO_PLUGINS=true /opt/anaconda3/bin/python scripts/build_sspp_split.py
```

**Kỳ vọng:** `SSPP_SPLIT_OK scenes=36 frames=2587 {"test": 12, "train": 16, "val": 8}`

**Kiểm:** `box_dim` phải là **9** (7 hình học + 2 vận tốc).

### Bước 3 — Train 3 nhánh

**Tạo:** `kaggle/train/sspp_arms.py`

**Chốt generator (2026-11-16):** Arm B dùng **đường stateful đúng method
paper** — cụm sống qua frame (`PlumeState`), trôi theo quán tính + cản khí
C = −0,15 m⁻¹ (Eq. 4–6), tan dần `exp(−t/T)` per cụm, raycast P_det
lognormal μ=−2,3/σ=1,1 + attenuation 0,02 m⁻¹ + occlusion. **Wet ground BẬT,
chỉ ở Arm B** — nó là một bộ phận của method augment (chạy trước bước sinh
cụm, đúng vị trí `dee.cpp`), không phải biến riêng. Arm A không chạy bước
simulate nào. Biến A/B = "có/không method augment đầy đủ".

Bẫy stateful + đa-worker (13c): **precompute cache keyed by token** — chạy
generator tuần tự 1 lần trước train, lưu điểm plume từng frame; train/eval
đọc cache. Δt phải verify bằng đo dịch chuyển nền (kỳ vọng 0,1 s nếu 10 Hz).

`distance_range_m`/`height_range_m` (stateless) KHÔNG dùng trên đường stateful
— khối sinh dán sát đuôi xe (`|v|·Δt`, cao 5–92 % box) + trôi thay thế.

| | Model 0 | Arm A | Arm B |
|---|---|---|---|
| Init | nuScenes ckpt | nuScenes ckpt | nuScenes ckpt |
| Train | không | 16 scene | 16 scene |
| Nền point cloud | – | `points[labels != 2]` | `points[labels != 2]` |
| Method augment (wet ground + plume stateful + raycast) | – | **không** | **có, p = 0,5, tại chỗ** |
| Steps / lr / batch / seed | – | 2000 / 1e-4 / 2 / 0 | giống Arm A |

**Ba điều bắt buộc:**

1. Bỏ `labels == 2` trước khi vào pipeline — cả hai arm.
2. Augment **tại chỗ**, không nhân đôi sample (nếu không, biến thay đổi là training exposure).
3. Log `n_points` mỗi 50 bước — arm B phải lớn hơn arm A khi augmentation bật.

**Kỳ vọng:** `SSPP_ARM_OK arm=A` và `SSPP_ARM_OK arm=B`

### Bước 4 — Eval

**Tạo:** `kaggle/train/sspp_eval.py`

Ba checkpoint × hai điều kiện:

| Điều kiện | Dữ liệu | Augment? |
|---|---|---|
| Test | 12 scene real spray | không |
| Clean control | nuScenes val 196 frame | không |

**Ngưỡng score `τ`:** quét trên frame sạch, lấy τ nhỏ nhất mà precision ≥ 0,5.
Đóng băng, dùng cho cả ba checkpoint.

**SPF proxy/frame** — hộp phải thoả cả ba:

```python
score >= tau
không khớp GT nào ở IoU >= 0.5
tâm hộp cách tâm cụm noise <= 1.5 m
```

Cụm noise: `spray.semantic_stats.cluster_angular` (eps 0,7°, minPts 3 — công thức paper).

**Kỳ vọng:** 1 dòng `SSPP_EVAL_TAU`, 6 dòng `SSPP_EVAL_CELL`, 1 dòng `SSPP_EVAL_OK`

### Bước 5 — Bảng kết quả

| Metric | Model 0 | Arm A | Arm B | Điều kiện đạt |
|---|---|---|---|---|
| AP@0,5 — test real spray | | | | B ≥ A |
| Recall — test real spray | | | | B ≥ A − 0,02 |
| Total FP/frame — test | | | | B < A |
| **SPF proxy/frame — test** | | | | **B < A ≥ 30 % tương đối, CI95 loại trừ 0** |
| AP@0,5 — clean control | | | | B ≥ A − 0,5 điểm |
| SPF proxy/frame — 50 và 130 km/h | | | | B < A ở **cả hai** |

Hàng 4 là hàng quyết định. Còn lại là chốt chặn.

**Phép đo thêm (miễn phí):** chạy cùng checkpoint hai lần trên cùng frame — bản gốc
và bản `points[labels != 2]`. Delta là tác động thuần của noise, không phụ thuộc
generator.

## Phạm vi

**Có:** nhánh điểm tin cậy (heatmap) của detector LiDAR-only.

đô thị; chỉ delta ghép cặp là chuyển được.
